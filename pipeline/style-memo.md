# Style memo — read by scriptgen.py before every script

Rules the scriptwriter must obey. `analyze.py` maintains the data-driven
section; edit the standing rules yourself anytime.

## Standing rules (human-set)

- **Every reel must name specific tools/models** (GLM 5.2, Claude Code,
  Gemini, a repo name). Evidence from @johannships' own channel (2026-07-05,
  50 shorts): named-tool content averages 3-10x the views of generic founder
  advice. His #1: "How to use GLM 5.2 in Claude Code" (4,000). His worst:
  "i sold 3 companies. steal my playbook" (82).
- **Proven formats for his audience, in order:** (1) tool-combo how-to
  ("How to use X in Y"), (2) challenger ("GLM 5.2 DESTROYS GPT 5.5"),
  (3) FREE angle ("Claude Code for FREE"), (4) receipts brag ("AI Employee
  got me 1M impressions", "Cut dev costs 95%"), (5) live one-shot demo.
- **Banned content types for the automated channel:** mindset/motivation,
  generic playbooks, personal-story-only, community shoutouts. (the owner can
  post those manually; the machine must not.)

- Per-repo beats: 22-32 words, hard max. V1 ran ~54 words per repo and felt
  long enough to scroll away from (owner feedback, 2026-07-05).
- Hook must contain a concrete number or a "right now" urgency claim.
- Operator angle is mandatory: name who makes money and how, in one clause.
- Numbers the voice clone could stumble on are written as words.
- No em dashes anywhere.
